# DriveReady OPC 2026 – AI Agent Course

## About
This repository contains my daily assignments, coding exercises, and practical implementations completed during the **DriveReady OPC 2026 AI Agent Course**.

Throughout this course, I am learning to build AI-powered applications and agents using Python, LLMs, APIs, and LangChain.

## Daily Progress

| Day | Topic | Work |
|---|---|---|
| Day 1 | First LLM API Call | Connected to an LLM using the Groq API and explored basic LLM interactions. |
| Day 2 | System Prompts and Python | Built a Sweet Crumbs Home Bakery chatbot using system prompts, few-shot prompting, and Python basics. |
| Day 3 | First Agent with LangChain | Built a bakery assistant using LangChain, prompt templates, memory, testing, and an agent demonstration. |
| Day 4 | Tools, Function Calling and Structured Output | Learning to build agents using Python tools, Pydantic structured outputs, and Google Sheets integration. |
